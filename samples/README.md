# 图型示例

每种图型一个示例项目，每个项目里有一个工作簿和一张图。在 SciCanvas 里用“打开项目”查看；也可以把 `.scv` 改成 `.zip` 解压，`tables/` 里是 CSV 表格，`graphs/` 里是 SVG 图。

工作簿第三行“注释”写明了每列该放什么。照着这个格式填自己的数据，选中列后点对应的图型即可。

| 文件 | 数据怎么放 |
| --- | --- |
| `01-折线图.scv` | 一个 X 列，后面接一个或多个 Y 列；每个 Y 列画成一条线 |
| `02-散点图.scv` | 一个 X 列和一个 Y 列，每行画一个点 |
| `03-点线图.scv` | X、Y 列，Y 列右侧放“Y 误差”列，误差棒自动对应左侧的 Y 列 |
| `04-柱状图.scv` | 用数字编号代表类别的 X 列；多个 Y 列在同一 X 处并排成组 |
| `05-堆叠柱图.scv` | X 列加多个 Y 列，按列的顺序从下往上堆叠 |
| `06-百分比堆叠柱图.scv` | 和堆叠柱图一样填原始数值，程序按每个 X 的总量换算成百分比 |
| `07-浮动柱图.scv` | X 列，后面 Y 列两两一组，按“下端、上端”的顺序排列 |
| `08-条形图.scv` | 和柱状图相同；X 列显示在纵轴，Y 值是横条的长度 |
| `09-面积图.scv` | X 列和 Y 列；面积填充到 0，负值填在基线下方 |
| `10-水平阶梯图.scv` | X 列和 Y 列；先水平保持，到下一个 X 再变化（如生存曲线） |
| `11-垂直阶梯图.scv` | X 列和 Y 列；在每个 X 处先竖直变到新值，再水平保持 |
| `12-样条曲线图.scv` | X 列和 Y 列；测量点可以稀疏，用自然三次样条连成平滑曲线 |
| `13-样条点线图.scv` | 同样条曲线图，另外在实测点处画符号 |
| `14-垂线图.scv` | X 列和 Y 列；每个点从 0 画一条竖线，适合谱峰 |

类别轴现在还不支持文字，类别先用 1、2、3… 编号，编号对应的名称写在 X 列的注释里。

示例由 `crates/scicanvas-core/tests/plot_samples.rs` 生成，测试会检查这里的文件和生成结果逐字节一致。修改示例后，运行以下命令重新生成：

```
cargo test -p scicanvas-core --features serde --test plot_samples -- --ignored
```
