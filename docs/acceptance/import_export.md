# Windows 人工验收：import_export

每条独立从指定示例开始。使用 release exe。Ctrl+K 打开命令搜索，输入下文引号内的完整命令名并回车。输出文件保存到个人临时验收目录。结果列由验收者填写，空白表示尚未操作。
