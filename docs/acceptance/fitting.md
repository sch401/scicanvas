### F138 拟合报告（参数表、ANOVA、置信带、预测带）

准备：打开 `samples/01-折线图.scv`。在项目树选择工作簿“反应釜升温”（点线示例按实际工作簿名选择唯一工作簿）；图形操作前点击唯一图形窗口。涉及 Excel、Word、PowerPoint 的条目需先打开对应 Microsoft Office 软件。

| # | 操作 | 预期 | 结果 |
|---|---|---|---|
| 1 | 选中 B 列，Ctrl+K 执行“非线性拟合”，选 ExpAssoc 并点“拟合” | 出现参数、标准误、R²、RSS 和收敛信息 | |
| 2 | 点击“置信/预测带”，记录拟合结果列与报告数值 | 图上出现对应带 | |
| 3 | 修改 B 第 1 行，Ctrl+K 打开“拟合报告…” | 曲线和报告同步，保留原结果列 | |
| 4 | 在报告点“重新编辑拟合设置”，修改初值后拟合，再 Ctrl+Z/Ctrl+Y | 原结果组更新，报告与曲线一起撤销重做 | |
| 5 | 保存重开，从“拟合报告…”查看 | 报告仍可定位到原结果和来源 | |
