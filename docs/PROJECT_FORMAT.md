# 项目文件格式

唯一读写入口在核心库 `project_file`（`serde` 特性），桌面界面使用相同入口。

## v9 类型化数据列（2026-10-18）

当前项目数据版本为 **v9**，`.scv` 容器版本仍为 1。一个 Book 对应一张独立表，沿用 `book_id + 列短名` 引用，不引入 Sheet 层或底部标签页。

新程序直接读取 v0–v8 `.scproj` / `.scv`，加载时在内存中迁移，原文件保持原样。保存时使用 v9。旧版程序按版本检查提示升级。原有 14 份 v8 `.scv` 示例保留为迁移样本，其 CSV/SVG 预览与 v9 生成结果逐字节比较。

列的 `data` 从字符串数组改为带 `kind` 的对象：

```json
{"kind":"num","values_le":"AAAAAAAA8D8=","missing":[0],"lexemes":[[0,"1.0"]]}
```

该示例只有一个非缺失数值 1.0，同时保留原始写法 `1.0`。字段含义：

- `num`：`values_le` 为 f64 小端原始字节的标准 Base64，保留 NaN、无穷与负零的位模式。`missing` 是 u64 位图，行 r 对应第 r/64 个字的第 r%64 位，1 表示缺失。位图和 NaN 独立，尾部填充位必须为 0。
- `text`：`values` 为字符串数组，保留混合文本；数值分析沿用旧版逐格解析规则，避免混合旧列的有效数字消失。
- `date_time`：`values_le` 为 UTC 毫秒 i64 小端字节的 Base64，使用同样的缺失位图。编辑和转换支持带时区的 ISO 8601，年在前的 `2026-10-18`、`2026/10/18`、`2026.10.18`、`2026年10月18日`（可跟 `14:30[:15.5]`，按 UTC），以及单独的四位年份（取 1 月 1 日）。其他纯整数和 `18/10/2026` 这类日月顺序不确定的写法拒绝转换，避免把数值误当时间戳。首个 v9 版本保存的毫秒整数原文仍可读取。
- `category`：`codes` 为 u32 编码，`levels` 是不重复的非空字符串字典，`ordered` 指定按字典顺序排序。`u32::MAX` 表示缺失。普通分类默认按标签排序，字典顺序的交互编辑和分类坐标轴继续规划。
- `lexemes`：数值/日期列可选的 `[行号, 原始文本]` 数组，保留前导零、`1.0`、科学计数、千分位和空白等写法。只在需要时保存，行号不得重复或越界，文本必须与对应值/缺失状态相符。整列特殊写法仍会占用逐格文本，后续显示格式可优化。

旧字符串列完整扫描后按数值/文本推断，空值独立标记；日期和分类由用户明确转换，避免把旧标识符误当日期或分类。转换、多列排序、行操作、复制/导出和撤销保持类型与原始写法。批量类型转换先检查全部目标列，某格失败时整次转换保持原数据。缺损 Base64、位图长度、尾位、字典编码、日期范围和不一致原文均拒绝加载。

界面列头右键或命令面板可转换类型。单格输入与类型不符时先确认转为文本，取消保留原数据。粘贴与已有类型冲突时整块保持原样，提示先转换列类型。日期/分类的完整显示格式、日期计算和分类轴仍属后续任务。

## `.scv` 容器

`.scv` 是 ZIP 压缩包，思路与 .docx 相同，改后缀为 .zip 或用解压软件即可查看内容：

| 条目 | 内容 |
| --- | --- |
| `mimetype` | 第一个条目，不压缩，内容为 `application/vnd.scicanvas.project+zip` |
| `manifest.json` | `scv_version`（容器版本，当前为 1）、`project_version`、生成程序，以及每个表格和图的编号、名称、项目文件夹路径和条目路径 |
| `project.json` | 完整项目数据，与 `.scproj` 的 JSON 完全相同，按下文的版本规则迁移 |
| `tables/<编号>-<名称>.csv` | 每个工作簿一份。UTF-8 BOM，CRLF 换行；表头为长名称（没有时用列标识），有单位时写成 `名称 (单位)`，可以直接用 Excel 打开或重新导入 |
| `graphs/<编号>-<名称>.svg` | 每张图一份，与“导出图形”生成的 SVG 相同 |

打开时只读 `project.json`。CSV 和 SVG 只是保存时生成的预览，被修改或删除都不影响打开。条目名称中 Windows 不允许的字符替换为 `_`，前缀编号保证不重名。`mimetype` 与约定的类型不符、缺少 `project.json`，或 `scv_version` 高于当前程序支持的版本时，拒绝打开并给出提示。单个条目解压后超过 2 GiB 也会拒绝，防止损坏的压缩包耗尽内存。条目时间固定为 1980-01-01，所以相同的项目总是生成相同的字节。

打开文件时按内容识别格式：以 `PK` 开头的按 `.scv` 读取，其他按 JSON 读取，允许带 UTF-8 BOM。保存时扩展名为 `.scproj` 写旧版 JSON，其他扩展名一律写 `.scv`。界面的另存为默认使用 `.scv`。`tests/scv_files.rs` 覆盖往返、条目内容、确定性输出、预览被改动、异类、损坏和更新版本的压缩包、旧版 JSON 以及保存失败。

## 项目数据版本

| 版本 | 结构 | 迁移 |
| --- | --- | --- |
| v0 | 无 `version`；单层 `Graph` | 补版本，再按 v1 转换 |
| v1 | 显式 `version: 1`；单层 `Graph` | 保留图形编号和名称，其余图形字段移入第一个图层 |
| v2 | `version: 2`；`Graph.page.layers` | 保留原有数据，补齐默认布局属性 |
| v3 | `version: 3`；图层增加 `placement` 和 `transparent` | 默认网格、不透明背景 |
| v4 | `version: 4`；列增加 `XError` / `YError`、`error_for`；图层增加 `error_bars` | 旧文件默认显示误差棒、端帽 6、线宽 1 |
| v5 | `version: 5`；新增 `StackedBar` / `PercentStackedBar` / `FloatingBar`，`PlotSpec.base_by_y` | 旧文件默认没有浮动柱下端映射 |
| v6 | `version: 6`；新增 `HorizontalBar` / `Area`，`Layer.area_opacity` | 旧文件填充透明度默认 0.35 |
| v7 | `version: 7`；新增 `Spline` / `SplineSymbol` / `VerticalDrop`，`Layer.labels` | 旧文件默认关闭数据标签 |
| v8 | `version: 8`；`Project.folders` 保存文件夹编号、名称、上级与对象归属 | 当前格式；旧文件对象放在根目录 |

`Layer` 的列映射来自展平序列化的 `PlotSpec`，仅保存一份。X/Y 引用、曲线独立 X 列、派生线、行范围、样式和对数轴设置随迁移保留。新添的变换和配色默认采用原始数据与 Origin 颜色。

`placement` 为可选的页面比例矩形（x、y、width、height），空值使用网格。自定义矩形参与独立定位和叠放，`transparent` 控制该图层背景。v2 的这些字段缺失时使用默认值；v3 文件带明确版本号，旧版程序会提示升级。

打开时检查版本、对象编号、列标识、页面尺寸、图层数和数值属性；旧的 `next_id` 小于现有最大对象编号时自动修复。明确高于当前支持的版本会提示升级，源文件保留。

`error_for` 保存同一工作簿内的来源列标识：Y 误差关联 Y 列；X 误差可关联 Y 列（该曲线专用）或 X 列（使用该 X 的曲线共用），曲线专用优先。缺省时按左侧相邻原始数据列推断，跳过误差列和派生结果列；修改角色、插入或删除列时固定已有的关联。删除来源列后写入空字符串，后续复用同名列标识也保持解除。重新指定误差角色可按当前位置重新关联。多个同轴误差列指向同一来源时采用最左侧一列。

`error_bars` 保存 `visible`、`cap` 和 `width`，端帽长度为非负有限数，线宽为正有限数，单位与页面逻辑画布相同。每行提供对称的非负有限误差；拟合、平滑结果及均值变换不继承原始测量误差。`tests/error_bars.rs` 覆盖关联、行对齐、对数裁剪、分组柱、SVG、撤销与旧版本默认值。

`base_by_y` 保存浮动柱上端 Y 列到下端列的映射；初次选择浮动柱时，按数据列顺序每两列配对，`y_keys` 改为保留上端列及派生线。切换到其他图型时继续使用这些 Y 列；配对映射保留，切回浮动柱可复用。删除下端后对应映射置为空字符串，该柱段隐藏，列标识复用也保持解除；可在属性中重新选择下端。每行上下端均有效时才生成柱段，允许反向区间。均值变换使用上下端同时有效的相同行求均值。

堆叠按原始行和相同 X 值对齐（均值变换后按 X 对齐），正负值分别累加。百分比堆叠按同组各符号绝对值总量分别归一到 ±100%，零总量保持零；先按最大绝对值缩放再求总量，避免有限输入的求和溢出和小量除法溢出。输入 Y 误差随段值按同一倍率换算，显示在段终点；累计与比例的统计误差传播后续单独实现。派生线保持原始数值，独立于柱段累加。`tests/bar_variants.rs` 验证数值、矩形几何、裁剪、SVG、配对稳定性、撤销和版本往返。

`HorizontalBar` 保持原始列映射，排版时交换数据点与误差方向：X 列映射到屏幕纵轴，Y 列映射到横轴。各图层的 `x_*` / `y_*` 属性、显式轴标题和视图范围始终指屏幕横/纵轴；默认标题按列方向生成。

`Area` 填充到零基线，对数 Y 轴使用显示下界。有效原始行连续时组成一段，每段按 X 排序；缺失行、无效值和对数过滤断开填充及边界线。均值变换按聚合后的 X 序列分段。跨基线处在页面坐标中求交并剖分，屏幕 Mesh 与 SVG 路径共用 `Triangles` 顶点。派生线独立绘制，`area_opacity` 为 0–1 的有限数，透明度为零时保留边界线。`tests/bar_area.rs` 覆盖方向、误差、面积积分、缺口、对数轴、图层裁剪、SVG、撤销与 v5/v6 迁移往返。

保存前完成校验和序列化，再写同目录唯一临时文件、同步、关闭，并替换目标文件。失败时清理临时文件；已有文件保持原内容。历史记录、窗口位置和选区仍由内存中的会话管理。

`tests/project_files.rs` 验证迁移、往返、损坏输入和保存失败。`tests/fixtures/legacy-*.svg` 是重构前实际生成的四种图，包含拟合曲线与选定行范围，按字符串逐字比较版面；新增图元时另加样例，保留这些兼容基线。

`Spline` / `SplineSymbol` 使用自然三次样条，两端二阶导数为零。连续原始行分段、段内按 X 排序，重复 X 处分开；均值视图按聚合后的 X 序列分段。每区间固定 16 段采样，采样值参与自动范围，非正对数片段断开。数值超出可表示范围的段使用原始折线；派生线独立绘制。大数据采样后续改为页面误差自适应。`VerticalDrop` 从原始点连接到零基线，对数轴使用显示下界。

`labels` 保存 `visible`、`source`（`Value` / `XY` / `Row` / `Column`）、`column`、`size` 和 `offset`。默认关闭、字号 11、偏移 6；字号应为有限正数，偏移为有限非负数。行号和指定列文本按原始行读取，均值视图使用数值或 X/Y，派生线不加标签。删除标签列会清除引用，复用列标识也保持解除。柱段显示各段值，百分比添加 `%`，标签向坐标框内定位并裁剪，指定列换行转为空格。`tests/spline_labels.rs` 用解析值及本机 SciPy 1.17.1 `CubicSpline(..., bc_type="natural")` 参考值验证样条，并覆盖垂线、标签、SVG、撤销及版本迁移。

`folders` 为虚拟项目文件夹数组，每项保存 `id`、`name`、`parent`、`items`。文件夹与工作簿/图形共用对象编号，根目录隐含存在，未归属任何文件夹的对象位于根目录。名称可用中文；文件夹最多 64 级，保存/打开校验编号重复、循环、缺失上级、无效或重复归属。删除文件夹时对象和子文件夹移到上级；删除工作簿或图形清理归属。新图形及新分析输出跟随来源工作簿目录，已有对象的位置保持。文件夹操作进入编辑事务，窗口显示和几何状态由当前界面会话维护。`tests/workspace.rs` 覆盖操作、非法移动、深度、分析目录、历史、v7/v8 往返和损坏文件。
