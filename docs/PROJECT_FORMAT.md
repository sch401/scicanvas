# 项目文件格式

## v25 直方图图型

图层与逐曲线的图型枚举增加 `Histogram`（直方图）：绘制时把各 Y 列的值按共同的等宽区间计数，区间不写入文件，随数据重新计算。旧版 v0–v24 项目没有该图型，读取不变；新文件写入 v25，旧程序会拒绝该版本。SCV 容器版本保持 1。

## v24 加权非线性拟合

非线性拟合定义（结果 Y 列的 `op`）增加可选字段 `weight`：`YError` 表示按与 Y 列关联的 Y 误差列加权（wᵢ = 1/σᵢ²）；不加权时不写入，缺省按不加权读取。拟合报告可选 `weighted` 为 true 时表示加权结果，此时 `rss`、`reduced_chi2` 为加权值；不加权时不写入。不加权拟合的 `input_digest` 计算方法不变；加权时把误差列的值一并计入，改误差列会触发重算。旧版 v0–v23 项目读取时全部为不加权；新文件写入 v24，旧程序会拒绝该版本。SCV 容器版本保持 1。

## v23 工作表筛选

工作簿可选字段 `filter` 保存按列设置的数值范围、文本包含和分类筛选，以及 `visible_only`（绘图和分析只使用可见行，缺省为 false，false 时不写入）；缺省表示显示全部行。筛选不删除源数据。旧版 v0–v22 项目读取时筛选为空；新文件写入 v23，旧程序会拒绝该版本。SCV 容器版本保持 1。

## v22 拟合精度状态

非线性拟合报告增加 `status`。它为 `PrecisionLimit` 时表示达到浮点精度极限；缺省或为 `Converged` 时按 `converged` 区分收敛和失败。v0–v21 旧报告根据原有 `converged` 标记迁移为 `Converged` 或 `Failed`，其余字段保持不变。v22 程序读取 v0–v22，旧程序会拒绝 v22 项目。SCV 容器版本保持 1。 拟合报告可选 `warnings` 为提示字符串数组，缺省为空，空时不写入；旧报告按空数组读取。本次维持 v22。

## v21 稳定拟合指纹与结果行域

v21 时项目格式读取 v0–v20，SCV 容器、.scfn 和图形模板仍为 v1。`input_digest` 与 `attempted_digest` 使用固定 FNV-1a 64 位算法，字段按明确标记、字符串长度及小端整数/浮点位编码。读入 v19/v20 时核对旧 DefaultHasher 指纹，匹配当前来源的成功/失败记录迁移到新摘要，否则保留数值并标记来源待重算。旧 input_hash/attempted_hash 只在迁移入口读取，新文件不写出。

列增加可选 `independent_rows: true`，标识独立采样的拟合/插值网格与带。默认 `Converged` 的原始列、残差和平滑等逐行数据继续参与来源表行操作。旧文件按已有操作及明确结果 X/Y 引用恢复行域，保持现有数据。列存储改用运行时 Arc 写时复制，磁盘表示仍使用原类型化列编码。

## v19–v20 非线性定义与数值报告

v19 在结果 Y 的 Nonlinear 操作保存函数快照、初值、固定/上下界/线性约束、来源 X/Y、行范围、输出 X 和带关联、重算模式及输入指纹。v20 的 `fit_report` 保存独立报告编号、Book/结果列关联、模型/参数/标准误/协方差/统计量、收敛状态和失败原因。报告和曲线使用同次求解，失败保留上次成功数值，旧文件缺定义或报告时保留已有数据与 Note。

## v18 自定义拟合函数库

当前项目数据版本为 v18，读取 v0–v17，.scv 容器版本仍为 1。Project.fit_functions 保存带稳定 id 的函数定义，每项 definition 含 name、formula、parameters（有序参数名）、initial（对应有限初值）和 constraints（线性约束文本）。函数与表/图/Note/目录共享编号分配器，但不作为工作区子窗口。

旧文件缺字段时默认空函数库，空库保存时省略该字段。载入校验编号、重复名称、标量表达式、参数、初值与约束，并修复过期的 next_id。项目保存和撤销快照保留定义；编译后的表达式语法树在使用时重建。非线性拟合结果仍为当次分析快照，修改库定义不自动重拟合已有结果。

## 独立拟合函数文件 .scfn

文件为 UTF-8 JSON，版本 1，最大 64 KiB，包含 version 与 function；function 使用上述定义字段，不保存项目 id 或数据列引用。不同项目载入时分配新的编号。示例：

~~~json
{"version":1,"function":{"name":"Line","formula":"y = a*x+b","parameters":["a","b"],"initial":[2,1],"constraints":"a >= 0"}}
~~~

名称、公式、参数、初值与约束复用拟合入口校验，损坏/未知版本/非有限初值和未知字段拒绝载入；保存复用同目录临时文件原子替换。新名称载入项目是一步可撤销修改；同名文件先进入编辑器，用户点击保存函数后更新。重命名保留稳定编号，保存时核对原定义，过期草稿保留并提示重新载入。

## v17 符号与逐点映射

v17 引入可选 symbol_fill、symbol_border_color、symbol_border_width、color_column、size_column、symbol_column 和 size_range；未设置的字段省略，旧项目继续原样显示。映射列属于该曲线的数据工作簿，删除来源列会清理映射。面积填充/轮廓映射沿用这些字段，不增加新的项目字段。

## v16 轴值参考线

当前项目数据版本为 v16，`.scv` 容器版本仍为 1，兼容 v0–v15。图层可选保存 `reference_lines` 数组，每条记录包含轴（X、左 Y 或右 Y）、轴值、RGB 颜色、线宽和实/虚线标记。旧项目缺少该字段时默认为空；无效轴值和线宽会拒绝加载。参考线跟随当前轴范围、对数刻度和右轴映射，不改变轴范围；对数轴上的非正值不绘制。界面与 SVG/PNG/PDF 共用场景图元，添加、编辑和删除支持撤销重做。

## v15 独立右 Y 轴范围与刻度格式

当前项目数据版本为 v15，`.scv` 容器版本仍为 1，兼容 v0–v14。每个图层新增 `y2_auto`、`y2_min`、`y2_max` 和可选 `y2_format`：右轴可独立自动/手动定范围及设置数字刻度格式；`y2_format` 缺省时跟随左 Y 轴格式。右轴自动范围默认开启，手动范围默认 0–10。绘图属性在图层有右轴曲线时显示这些设置；左右轴线性/对数切换仍共用图层的 `y_log`。

v14 及更早项目缺少这些字段时，右轴继续自动定范围并沿用左轴格式，既有图形外观保持一致。默认值在保存时省略；修改后的右轴设置随图层保存，并在 JSON/SCV 往返与撤销中保留。

## 图形模板 `.scgt`

`.scgt` 是版本 1 的独立 JSON 文件，与项目格式独立，当前项目数据版本为 v18。它保存图形名称、页面/图层布局、坐标轴和曲线样式，并将数据映射保留为列短名；不包含工作簿数据或工作簿编号。应用模板时选中一个目标工作簿，所有图层按列短名重绑定；缺少所需列时拒绝创建图形。应用成功后新增图形作为一步撤销操作。

## v14 缺失的浮动柱下端（2026-10-23）

v14 引入的项目数据版本兼容 v0–v13。曲线对象增加可选 `base_missing: true`，表示下端列已删除，此时 `mapping.base` 为 `null`。未设置时沿用旧版含义，同时指定有效下端和缺失标记的文件拒绝加载。内存编辑视图继续使用原有空下端标记。

保存、重开、切换图型、复用已删除的列名及删除主表后重新绑定，均保留柱段隐藏状态，避免自动配对到其他列。旧文件缺省该标记为 false，旧版平行映射中的空下端标记保留并在保存时转换。旧版程序根据版本号提示更新。

## v13 页面文字与图例位置（2026-10-23）

v13 引入的项目数据版本为 v13，SCV 容器版本仍为 1，兼容 v0–v12。`Page.annotations` 保存 `{id, text, position, size_pt, color, rich}`，位置为整页左上角比例 `[x,y]`，字号为 pt，颜色为 RGB 字节；`next_text_id` 保留递增编号，删除后不复用。加载拒绝重复/非法编号、非有限或越界位置与字号。`Layer.legend_position` 为可选整页比例，缺省为自动避让；图例隐藏与手动位置分别保存，恢复自动清空位置并显示图例。

旧项目缺省无文字对象、图例自动避让，v12 科学文字格式原样保留。屏幕、SVG、PNG 与 PDF 共享页面对象排版，选区边框属于临时界面状态。添加、拖动、修改、删除和恢复自动避让使用原有项目撤销事务。

## v11 曲线映射（2026-10-20）

v11 引入 `plots` 曲线映射数组，SCV 容器版本仍为 1，初版兼容 v0–v10。已绑定数据的图层通过 `plots` 保存每条曲线的 `mapping` 和可选 `style`，映射列使用 `{ "book": 2, "col": "B" }`，包含 y、x、base、rows、line_only。`x_override` 保留属性编辑中是否显式指定过 X 的信息。空图或失去数据源的旧空图保留占位编辑配置。当前 v18 继续使用该曲线 wire 结构，并保存后续版本新增字段。

读取时把 v11 曲线对象转换为内存曲线描述，绘图和分析通过相同的 CurveMapping 解析；编辑控件使用临时 `PlotSpec` 草稿。旧版的本表列名和 `列@工作簿` 引用仍可读。拒绝重复来源、非法编号/列标识、无效行范围及一条曲线中不匹配的表引用。加载只修改内存，原文件保持原样，保存继续使用同目录临时文件替换。

唯一读写入口在核心库 `project_file`（`serde` 特性），桌面界面使用相同入口。

## v10 Note 文档（2026-10-18）

v10 引入 Note 文档，ZIP 容器版本仍为 1。兼容 v0–v9，旧项目默认没有 Note，加载时保留原文件，保存为 v10。旧程序会提示更新，避免遗漏笔记。

`Project.notes` 保存 `{id, name, text}`，内容为 UTF-8 文本，允许换行和制表符。Note 与表格、图形、文件夹共享唯一编号，支持目录归属与撤销重做。`project.json` 为权威内容，`.scv` 的 `notes/<编号>-<名称>.txt` 与 manifest 的 notes 清单提供可直接读取的预览。

计算结果通过“保存为 Note”保存当次报告文本快照，后续修改源数据或 Note 不自动重算。Note 的 Markdown 渲染、富文本和自动结果日志仍待实现。

## v9 类型化数据列（2026-10-18）

v9 引入类型化数据列，`.scv` 容器版本仍为 1。一个 Book 对应一张独立表，沿用 `book_id + 列短名` 引用，不引入 Sheet 层或底部标签页。

新程序直接读取 v0–v8 `.scproj` / `.scv`，加载时在内存中迁移，原文件保持原样。保存时使用 v9。旧版程序按版本检查提示升级。原有 14 份 v8 `.scv` 示例保留为迁移样本，其 CSV/SVG 预览与 v9 生成结果逐字节比较。

列的 `data` 从字符串数组改为带 `kind` 的对象：

```json
{"kind":"num","values_le":"AAAAAAAA8D8=","missing":[0],"lexemes":[[0,"1.0"]]}
```

该示例只有一个非缺失数值 1.0，同时保留原始写法 `1.0`。字段含义：

- `num`：`values_le` 为 f64 小端原始字节的标准 Base64，保留 NaN、无穷与负零的位模式。`missing` 是 u64 位图，行 r 对应第 r/64 个字的第 r%64 位，1 表示缺失。位图和 NaN 独立，尾部填充位必须为 0。
- `text`：`values` 为字符串数组，保留混合文本；数值分析沿用旧版逐格解析规则，避免混合旧列的有效数字消失。
- `date_time`：`values_le` 为 UTC 毫秒 i64 小端字节的 Base64，使用同样的缺失位图。编辑和转换支持带时区的 ISO 8601，年在前的 `2026-10-18`、`2026/10/18`、`2026.10.18`、`2026年10月18日`（可跟 `14:30[:15.5]`，按 UTC），以及单独的四位年份（取 1 月 1 日）。其他纯整数和 `18/10/2026` 这类日月顺序不确定的写法拒绝转换，避免把数值误当时间戳。首个 v9 版本保存的毫秒整数原文仍可读取。
- `category`：`codes` 为 u32 编码，`levels` 是不重复的非空字符串字典，`ordered` 指定按字典顺序排序。`u32::MAX` 表示缺失。普通分类默认按标签排序，字典顺序的交互编辑和分类坐标轴继续规划。
- `lexemes`：数值/日期列可选的 `[行号, 原始文本]` 数组，保留前导零、`1.0`、科学计数、千分位和空白等写法。只在需要时保存，行号不得重复或越界，文本必须与对应值/缺失状态相符。整列特殊写法仍会占用逐格文本，后续显示格式可优化。

旧字符串列完整扫描后按数值/文本推断，空值独立标记；日期和分类由用户明确转换，避免把旧标识符误当日期或分类。转换、多列排序、行操作、复制/导出和撤销保持类型与原始写法。批量类型转换先检查全部目标列，某格失败时整次转换保持原数据。缺损 Base64、位图长度、尾位、字典编码、日期范围和不一致原文均拒绝加载。

界面列头右键或命令面板可转换类型。单格输入与类型不符时先确认转为文本，取消保留原数据。粘贴与已有类型冲突时整块保持原样，提示先转换列类型。日期/分类的完整显示格式、日期计算和分类轴仍属后续任务。

## `.scv` 容器

`.scv` 是 ZIP 压缩包，思路与 .docx 相同，改后缀为 .zip 或用解压软件即可查看内容：

| 条目 | 内容 |
| --- | --- |
| `mimetype` | 第一个条目，不压缩，内容为 `application/vnd.scicanvas.project+zip` |
| `manifest.json` | `scv_version`（容器版本，当前为 1）、`project_version`、生成程序，以及每个表格和图的编号、名称、项目文件夹路径和条目路径 |
| `project.json` | 完整项目数据，与 `.scproj` 的 JSON 完全相同，按下文的版本规则迁移 |
| `tables/<编号>-<名称>.csv` | 每个工作簿一份。UTF-8 BOM，CRLF 换行；表头为长名称（没有时用列标识），有单位时写成 `名称 (单位)`，可以直接用 Excel 打开或重新导入 |
| `graphs/<编号>-<名称>.svg` | 每张图一份，与“导出图形”生成的 SVG 相同 |

打开时只读 `project.json`。CSV 和 SVG 只是保存时生成的预览，被修改或删除都不影响打开。条目名称中 Windows 不允许的字符替换为 `_`，前缀编号保证不重名。`mimetype` 与约定的类型不符、缺少 `project.json`，或 `scv_version` 高于当前程序支持的版本时，拒绝打开并给出提示。单个条目解压后超过 2 GiB 也会拒绝，防止损坏的压缩包耗尽内存。条目时间固定为 1980-01-01，所以相同的项目总是生成相同的字节。

打开文件时按内容识别格式：以 `PK` 开头的按 `.scv` 读取，其他按 JSON 读取，允许带 UTF-8 BOM。保存时扩展名为 `.scproj` 写旧版 JSON，其他扩展名一律写 `.scv`。界面的另存为默认使用 `.scv`。`tests/scv_files.rs` 覆盖往返、条目内容、确定性输出、预览被改动、异类、损坏和更新版本的压缩包、旧版 JSON 以及保存失败。

项目文件的 `plots` 数组仅保存一份权威曲线映射。内存中的 `LayerSpec` 以有序 `Vec<Plot>` 保存曲线；`PlotSpec` 只用于编辑草稿和旧格式边界转换。X/Y 引用、曲线独立 X 列、派生线、行范围与样式随迁移保留。新添的变换和配色默认采用原始数据与 Origin 颜色。

`placement` 为可选的页面比例矩形（x、y、width、height），空值使用网格。自定义矩形参与独立定位和叠放，`transparent` 控制该图层背景。v2 的这些字段缺失时使用默认值；v3 文件带明确版本号，旧版程序会提示升级。

打开时检查版本、对象编号、列标识、页面尺寸、图层数和数值属性；旧的 `next_id` 小于现有最大对象编号时自动修复。明确高于当前支持的版本会提示升级，源文件保留。

`error_for` 保存同一工作簿内的来源列标识：Y 误差关联 Y 列；X 误差可关联 Y 列（该曲线专用）或 X 列（使用该 X 的曲线共用），曲线专用优先。缺省时按左侧相邻原始数据列推断，跳过误差列和派生结果列；修改角色、插入或删除列时固定已有的关联。删除来源列后写入空字符串，后续复用同名列标识也保持解除。重新指定误差角色可按当前位置重新关联。多个同轴误差列指向同一来源时采用最左侧一列。

`error_bars` 保存 `visible`、`cap` 和 `width`，端帽长度为非负有限数，线宽为正有限数，单位与页面逻辑画布相同。每行提供对称的非负有限误差；拟合、平滑结果及均值变换不继承原始测量误差。`tests/error_bars.rs` 覆盖关联、行对齐、对数裁剪、分组柱、SVG、撤销与旧版本默认值。

`base_by_y` 保存浮动柱上端 Y 列到下端列的映射；初次选择浮动柱时，按数据列顺序每两列配对，`y_keys` 改为保留上端列及派生线。切换到其他图型时继续使用这些 Y 列；配对映射保留，切回浮动柱可复用。删除下端后对应映射置为空字符串，该柱段隐藏，列标识复用也保持解除；可在属性中重新选择下端。每行上下端均有效时才生成柱段，允许反向区间。均值变换使用上下端同时有效的相同行求均值。

堆叠按原始行和相同 X 值对齐（均值变换后按 X 对齐），正负值分别累加。百分比堆叠按同组各符号绝对值总量分别归一到 ±100%，零总量保持零；先按最大绝对值缩放再求总量，避免有限输入的求和溢出和小量除法溢出。输入 Y 误差随段值按同一倍率换算，显示在段终点；累计与比例的统计误差传播后续单独实现。派生线保持原始数值，独立于柱段累加。`tests/bar_variants.rs` 验证数值、矩形几何、裁剪、SVG、配对稳定性、撤销和版本往返。

`HorizontalBar` 保持原始列映射，排版时交换数据点与误差方向：X 列映射到屏幕纵轴，Y 列映射到横轴。各图层的 `x_*` / `y_*` 属性、显式轴标题和视图范围始终指屏幕横/纵轴；默认标题按列方向生成。

`Area` 填充到零基线，对数 Y 轴使用显示下界。有效原始行连续时组成一段，每段按 X 排序；缺失行、无效值和对数过滤断开填充及边界线。均值变换按聚合后的 X 序列分段。跨基线处在页面坐标中求交并剖分，屏幕 Mesh 与 SVG 路径共用 `Triangles` 顶点。派生线独立绘制，`area_opacity` 为 0–1 的有限数，透明度为零时保留边界线。`tests/bar_area.rs` 覆盖方向、误差、面积积分、缺口、对数轴、图层裁剪、SVG、撤销与 v5/v6 迁移往返。

保存前完成校验和序列化，再写同目录唯一临时文件、同步、关闭，并替换目标文件。失败时清理临时文件；已有文件保持原内容。历史记录、窗口位置和选区仍由内存中的会话管理。

`tests/project_files.rs` 验证迁移、往返、损坏输入和保存失败。`tests/fixtures/legacy-*.svg` 是重构前实际生成的四种图，包含拟合曲线与选定行范围，按字符串逐字比较版面；新增图元时另加样例，保留这些兼容基线。

`Spline` / `SplineSymbol` 使用自然三次样条，两端二阶导数为零。连续原始行分段、段内按 X 排序，重复 X 处分开；均值视图按聚合后的 X 序列分段。每区间固定 16 段采样，采样值参与自动范围，非正对数片段断开。数值超出可表示范围的段使用原始折线；派生线独立绘制。大数据采样后续改为页面误差自适应。`VerticalDrop` 从原始点连接到零基线，对数轴使用显示下界。

`labels` 保存 `visible`、`source`（`Value` / `XY` / `Row` / `Column`）、`column`、`size` 和 `offset`。默认关闭、字号 11、偏移 6；字号应为有限正数，偏移为有限非负数。行号和指定列文本按原始行读取，均值视图使用数值或 X/Y，派生线不加标签。删除标签列会清除引用，复用列标识也保持解除。柱段显示各段值，百分比添加 `%`，标签向坐标框内定位并裁剪，指定列换行转为空格。`tests/spline_labels.rs` 用解析值及本机 SciPy 1.17.1 `CubicSpline(..., bc_type="natural")` 参考值验证样条，并覆盖垂线、标签、SVG、撤销及版本迁移。

`folders` 为虚拟项目文件夹数组，每项保存 `id`、`name`、`parent`、`items`。文件夹与工作簿/图形共用对象编号，根目录隐含存在，未归属任何文件夹的对象位于根目录。名称可用中文；文件夹最多 64 级，保存/打开校验编号重复、循环、缺失上级、无效或重复归属。删除文件夹时对象和子文件夹移到上级；删除工作簿或图形清理归属。新图形及新分析输出跟随来源工作簿目录，已有对象的位置保持。文件夹操作进入编辑事务，窗口显示和几何状态由当前界面会话维护。`tests/workspace.rs` 覆盖操作、非法移动、深度、分析目录、历史、v7/v8 往返和损坏文件。

## 自定义函数参数上限（第六轮 O4）

参数上限由 7 调整为 12，项目格式保持 v21，v18 起的函数库和 .scfn v1 复用同一个 MAX_PARAMS 校验，不增加字段。旧文件中的 1–7 参数函数继续读取；包含 8–12 参数函数的项目和 .scfn 需要本批程序，旧版 7 参数程序会拒绝载入。13 参数仍拒绝，并提示“参数数量必须在 1 到 12 之间”。
