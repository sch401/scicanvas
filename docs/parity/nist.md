# NIST StRD 离线认证值对照

来源：[NIST/ITL StRD](https://www.itl.nist.gov/div898/strd/)。原始 .dat、SHA-256 和下载日期见 tests/nist/{nls,lls}/MANIFEST.txt。

复现：`SCICANVAS_NIST_REPORT=docs/parity/nist.md cargo test --profile ci -p scicanvas-core --test nist -- --nocapture`（PowerShell 请先设置同名环境变量）。

LRE = −log10(|估计−认证|/|认证|)，上限 11；认证值为 0 时用绝对误差。非线性 Start 2：参数低/中 ≥7、高 ≥6，RSS ≥6，SE ≥4。Start 1 同精度，或明确未收敛 / RSS 高于认证值 1%。线性：参数、SE、残差标准差低/中 ≥9、高 ≥7。Wampler1–4 按第六轮指南使用 9 位阈值（官方文件统一标 Higher）。不支持项保留在表中，未达标项登记显式已知失败，不改变算法和阈值。
